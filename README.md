# Zepto Data & AI Platform

This project implements an end-to-end AI/ML platform consisting of
three connected capabilities:

1. Data Engineering Pipeline
2. Analytics and Machine Learning Pipeline
3. GenAI Support Assistant

## Project Modules

### 1. Data Pipeline
Path: /data_pipeline
Scrapes product-style data, cleans it, converts currencies,
stores it in SQLite and performs SQL and pandas analysis.

### 2. Analytics
Path: /analytics
Performs data profiling, exploratory analysis,
preprocessing, machine learning and evaluation.

### 3. Support Assistant
Path: /support_assistant
Builds a document-grounded GenAI assistant for answering
policy-related questions.
